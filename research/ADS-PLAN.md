## 1. 한 장 요약

| 질문 | 결론 |
|---|---|
| 지금 github.io 주소로 광고 되나? | **애드핏은 시도 가능**(공식 정책에 도메인 요건 없음, 신청 비용 0원). **애드센스는 사실상 불가**(2023년 이후 루트 도메인 소유 인증 필요 — github.io 루트는 GitHub 소유). |
| 도메인을 먼저 사야 하나? | **아니오.** 애드핏 신청에는 불필요. 애드센스로 갈 때 사면 된다(연 1~2만 원). |
| 그럼 첫 수순은? | **① 카카오 애드핏 가입 → 매체 등록 → 광고단위 발급** (아래 §5). 발급 코드를 Claude에게 주면 삽입은 준비된 슬롯에 바로 된다. |
| 얼마나 벌리나? | 냉정하게 **월 수백~수천 원** 수준부터 시작. 최소 지급액 5만 원 도달에 1년 이상 걸릴 수 있음 (§7). |
| 사이트 쪽 준비는? | **완료.** 광고 슬롯 3곳(자리만, 화면 변화 0) + 활성화 헬퍼 골격 + 개인정보처리방침 페이지(`docs/privacy.html`). |

## 2. 조사 종합 — 네트워크별 판단

### 카카오 애드핏 — 1순위

- **개인(비사업자) 가입 가능.** 카카오 계정 + 휴대폰 본인인증이면 끝. 단 이름·주민등록번호가 계정에 등록되고 **이후 변경 불가**(원천징수·정산용).
- **도메인 요건 없음.** 운영정책 전문에 서브도메인·무료 호스팅 금지 조항이 없다(검증 2회 — 원 조사 + 독립 재확인). 단 운영정책 4.2조의 심사 항목에 "매체의 소유관계"·"콘텐츠의 질적·양적 품질"·"트래픽의 질적·양적 품질"이 포함되므로, github.io 서브도메인이 소유관계 판단에서 어떻게 취급되는지는 심사자 재량이다. 애드핏의 주력 매체인 티스토리 자체가 `*.tistory.com` 서브도메인. 소유권 확인도 DNS가 아니라 "광고 스크립트를 실제 설치 → 광고 요청 수신 확인 → 심사" 방식이라 github.io로도 등록·심사 흐름이 막히지 않는다.
- 단, **github.io 주소 그대로 승인된 명시적 성공 후기는 미확보** — 불확실성으로 남음. 신청 비용이 0원이므로 먼저 넣어 보고, 거절되면 사유를 보고 대응하는 것이 합리적.
- **심사 순서 주의: 스크립트를 사이트에 안 붙이면 심사가 보류된다.** "광고단위 발급 → 스크립트 배포 → 심사"가 정순서. 통상 1~2영업일, 보류를 겪으면 1주일+.
- 주요 거절 사유: 콘텐츠 양 부족(툴 사이트 최대 리스크), 오클릭 유발 배치, 페이지당 광고 4개 초과, 접근 제한 사이트. 성인·도박·게임 **아이템 거래**는 금지지만 게임 시뮬레이터 자체는 금지 대상이 아님.

### 구글 애드센스 — 2차 (도메인 구입 후)

- 2023년 정책 변경 후 사이트 등록이 **루트 도메인 단위 인증**으로 바뀜. `jaredlee1218.github.io`의 루트는 GitHub 소유라 인증 불가 → **커스텀 도메인 구입이 선행 조건** (Public Suffix List 등재로 되는 경우가 있다는 보고도 있으나 승인 성공담은 미확인 — 시간 낭비 확률 높음).
- 도구/시뮬레이터 단독 사이트는 **"낮은 가치 콘텐츠(low value content)" 거절의 단골.** 통과 정석: 각 페이지에 설명·FAQ 텍스트 + 지원 글 10~20개 + 소개/문의/개인정보처리방침 페이지 + 1~2개월 운영 흔적.
- 도메인을 나중에 바꾸면 심사를 새로 받으므로, **애드센스 신청 전에 도메인을 확정**할 것.
- 승인 후: `docs/ads.txt` 한 줄 + `index.html` head 스니펫. 수익 $10 도달 시 PIN 우편(2~6주), $100부터 계좌 송금.

### 쿠팡 파트너스 — 병행 가능 (문턱 최저)

- 가입 즉시 활동 가능(최종 승인 심사는 누적 판매 15만 원 도달 시). 개인 비사업자 가능, 수수료 약 3%.
- 게이밍 기어(마우스·키보드) 추천과 자연스럽게 결합 가능. 단 대가성 문구("이 사이트는 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다")를 **본문에 상시 노출**해야 함.
- GitHub Pages 약관과의 충돌이 가장 적음(제휴 링크는 후원 링크 수준의 부수적 수익화로 해석 여지 큼).

### 기타

- 애드픽·텐핑(SNS 확산형)·데이블(언론사급 B2B)은 이 사이트에 부적합.
- 호스팅: GitHub Pages에서 배너 광고는 "주목적이 상업 거래"가 아니면 관행상 허용 영역. 리스크가 걱정되면 Cloudflare Pages 이전이 무비용(이 프로젝트는 상대 경로만 쓰므로 코드 수정 0) — 당장은 불필요.

## 3. 추천 경로 (순서와 이유)

```
[지금]   1차: 카카오 애드핏 — github.io 그대로 신청 (도메인 불요, 비용 0)
              └ 거절 시: 사유 확인 → 커스텀 도메인 + 콘텐츠 보강 → 재신청
[선택]   병행: 쿠팡 파트너스 — 문턱 없음, 결과 화면에 기어 추천 링크
[1~2개월 후] 2차: 커스텀 도메인 구입(jeungbaram.kr/.com 등) + 정적 가이드 글 보강
              → 구글 애드센스 신청 (수익 애드핏의 3~5배 기대)
```

- 애드핏이 1차인 이유: 유일하게 **지금 주소로 시도 가능한 배너 네트워크**이고, 승인이 빠르며(1~2영업일), 슬롯 규격(300x250·320x100)이 애드센스와 동일해 나중에 갈아타도 슬롯 설계를 재사용한다.
- 애드센스를 미루는 이유: 도메인 미소유(치명, 즉시 해결 가능) > 텍스트 콘텐츠 부족(주 거절 사유) > 사이트 연령/트래픽(시간이 해결). 지금 넣으면 거절 이력만 쌓인다.

## 4. 사이트에 이미 준비된 것 (광고 슬롯 3곳)

**지금은 자리만 있고 광고 코드는 없다. 슬롯은 전부 `hidden` — 화면에 아무것도 안 보인다.**
활성화는 `docs/js/app.js`의 `AD_UNITS`에 발급 정보를 기입하고 주석 블록을 해제하는 순간부터 (§6).

| 슬롯 | 위치 | 규격 | 근거 |
|---|---|---|---|
| **A (주력)** `#ad-slot-result` | 결과 화면, 버튼 그룹 아래 (`docs/index.html` `#screen-result` 끝) | **300x250** 중형 직사각형 | 과업 완료 지점·체류 길고·스크롤 종단 — 시인성/비방해성 최적. 버튼과 24px 이격(오클릭 정책) |
| **B** `#ad-slot-dex` | 꿀잼 사전 본문 끝 (`#dex-body` **바깥** 형제 — innerHTML 재생성에 안 부서짐) | **320x100** 모바일 배너 | 읽기 완료 지점. 320x50은 채택 안 함(320x100이 CTR·RPM 우위) |
| **C (선택적)** `#ad-slot-select` | 챔피언 선택 화면, 그리드 아래·푸터 위 | **320x100** | 그리드 끝이라 뷰포트 밖 로드 → CLS 실질 0. 트래픽 생기기 전엔 비워 둬도 됨 |
| **제외** | **드래프트 화면 전체** + 앵커(하단 고정)형 + 자동 광고 | — | 카드 탭·리롤 버튼 밀집 = 오클릭 유발 배치(정책 제재 사유). SPA 단일 URL이라 자동 광고는 화면별로 끌 수 없음 |

구현된 CLS/정책 안전장치 (`docs/css/app.css`·`docs/js/app.js`):

- 활성화 시 `min-height` 공간 예약(직사각형 270px / 배너 120px) — 광고 로드 전후 레이아웃 밀림 0. 미채움이어도 접지 않음.
- 화면이 **표시된 후**에만 광고 로드(`showScreen` → `activateAdSlot`) — hidden 상태 로드 실패(availableWidth=0) 방지.
- 슬롯당 1회 로드 플래그 — 화면 재진입 시 재로드 금지(무페이지로드 리프레시는 정책 위반 소지).
- 320px 초소형 뷰포트에서 풀블리드 처리(300px 광고가 3px 넘치는 문제).
- 화면당 광고 1개, 총 3개 이하 — 애드핏 한도(4개)와 Better Ads 밀도(30%) 모두 여유.

## 5. 사용자 직접 실행 체크리스트

### STEP 0 — 시작 전 결정 (1분)

- [ ] **주민등록번호 등록 각오**: 애드핏 개인 계정은 가입 시 이름·주민번호가 등록되고 **이후 변경 불가**(원천징수용). 싫으면 여기서 중단.
- [ ] 수익 기대치 확인: §7 읽고 "월 수백~수천 원부터 시작"임을 수용.

### STEP 1 — 애드핏 가입 (5~10분)

1. [ ] https://adfit.kakao.com 접속 → **"애드핏 시작하기"** 클릭 → 카카오 계정 로그인.
2. [ ] 약관 동의 → 회원 유형에서 **"개인"** 선택 (사업자 아님 — 사업자등록증 불필요).
3. [ ] **휴대폰 본인인증** 진행 (본인 명의 휴대폰 필요 — 이 단계에서 이름·주민번호가 등록됨).
4. [ ] 알림(이메일/카카오톡) 설정 → 계정 생성 완료.
5. 정산 계좌는 지금 필요 없음 — 나중에 수익 5만 원 도달 후 지급 요청 때 본인 명의 계좌 등록.

### STEP 2 — 매체(사이트) 등록 (5분)

1. [ ] 애드핏 대시보드 → **매체 관리 → 새 매체 등록** (메뉴 명칭은 개편에 따라 다를 수 있음 — "웹" 유형 선택).
2. [ ] 매체 유형: **웹(Web)**.
3. [ ] URL 입력: `https://jaredlee1218.github.io/jeungbaram/`
4. [ ] 매체명: `증바람 시뮬레이터` (자유).
5. [ ] 카테고리: 게임 관련 항목 선택.
6. 등록 직후 심사가 끝나는 게 아님 — **스크립트가 실제 배포돼 광고 요청이 수신된 뒤에 심사가 진행**된다 (STEP 4 이후).

### STEP 3 — 광고단위 발급 (5분)

발급할 단위 **3개** (각각 `DAN-`으로 시작하는 코드가 나옴):

- [ ] ① 이름 `결과화면-300x250` — 사이즈 **300x250**
- [ ] ② 이름 `사전-320x100` — 사이즈 **320x100**
- [ ] ③ 이름 `선택화면-320x100` — 사이즈 **320x100** (선택 — 처음엔 ①②만 해도 됨)

### STEP 4 — 발급 코드를 Claude에게 전달

- [ ] 발급된 **광고단위 코드(DAN-xxxxxxxxxxxx) 3개를 어느 슬롯용인지와 함께** Claude에게 전달.
  전달 예: "결과 DAN-AAA, 사전 DAN-BBB, 선택 DAN-CCC 삽입해줘"
- 이후는 §6대로 Claude가 삽입·검증 → 커밋·푸시하면 배포 완료.

### STEP 5 — 심사 대기·결과 대응 (1~2영업일, 보류 시 1주+)

- [ ] 배포 후 사이트에 접속해 슬롯 위치에 광고(또는 빈 예약 공간)가 뜨는지 확인.
- [ ] 애드핏 대시보드에서 심사 상태 확인. **승인** → 끝, 수익 집계 시작.
- [ ] **보류/거절 시**: 통보된 사유 확인 후 Claude에게 공유. 대응 매뉴얼:
  - "광고 미설치" → 배포 상태 재확인 (스크립트가 실제로 요청을 보내야 심사 진행).
  - "콘텐츠 부족" → 커스텀 도메인 구입 + 정적 가이드 글 페이지 보강 후 재신청 (애드센스 준비와 겸용).
  - 사유 미공개 거절 → 도메인 구입 후 재신청이 다음 수.

### STEP 6 (선택) — 쿠팡 파트너스 병행

- [ ] https://partners.coupang.com 가입 (쿠팡 계정, 개인 가능) → 활동 채널에 사이트 URL 등록.
- [ ] 게이밍 기어 상품 링크 생성 → Claude에게 전달하면 결과 화면 등에 추천 블록으로 삽입.
- [ ] 대가성 문구 상시 노출 필수 (삽입 시 Claude가 함께 넣음).

### STEP 7 (1~2개월 후) — 애드센스 준비

- [ ] 커스텀 도메인 구입(가비아/Cloudflare 등, 연 1~2만 원) — **신청 전에 확정** (나중에 바꾸면 재심사).
- [ ] GitHub Pages에 커스텀 도메인 연결 + HTTPS (무료 — Claude가 설정 안내).
- [ ] 정적 텍스트 콘텐츠 보강: 증강 티어 해설·챔피언 공략 등을 크롤러가 읽는 정적 페이지 10~20개로 (기존 데이터 재활용 — Claude 작업).
- [ ] 서치콘솔 등록 + sitemap → 일 방문 수십 확인되면 https://adsense.google.com 신청.
- [ ] 거절 시 글 1~2개 보강 후 즉시 재신청 반복 (2025~26 통설상 유효).

## 6. 코드가 오면 Claude가 하는 일

사용자가 STEP 4에서 광고단위 코드를 주면:

1. `docs/js/app.js`의 `AD_UNITS`에 기입:
   ```js
   var AD_UNITS = {
     select: { unit: "DAN-CCC...", width: 320, height: 100 },
     dex:    { unit: "DAN-BBB...", width: 320, height: 100 },
     result: { unit: "DAN-AAA...", width: 300, height: 250 },
   };
   ```
2. `activateAdSlot()` / `loadAdfitScript()` 안의 "여기에 애드핏 스크립트" 주석 블록 해제
   (공식 삽입 코드 형식 그대로 — `<ins class="kakao_ad_area">` + `ba.min.js` 1회 주입).
3. 개인정보처리방침(`docs/privacy.html`)에 카카오(애드핏) 행태정보 수집 고지가 반영돼 있는지 확인 — 광고 SDK 부착과 동시에 게시가 법령 가이드라인·광고 계약 양쪽 요구사항.
4. 테스트(`test-draft`·`test-recommend`·`test-e2e`·`validate-data` 등) 통과 확인 → 커밋·푸시 → 배포 확인.

## 7. 수익 현실 기대치

- 애드핏은 CPC 중심, 클릭 단가 체감 수십 원. 실측: **일 방문 750명 블로그가 1년에 27,655원**(월 555~4,678원). 신생 게임 도구 사이트면 **최소 지급액 5만 원 도달에 1년 이상** 걸릴 수 있다.
- 애드센스 전환 시 통설상 애드핏의 3~5배("10 대 2~3") — 그래서 애드핏은 "애드센스 승인 전 워밍업/병행" 포지션.
- 세금: 개인은 지급 시 3.3% 원천징수(사업소득). **다음 해 5월 종합소득세 합산 신고 대상**(소액이면 대체로 환급).
- 결론: 단기 수익 목적이 아니라 **"광고 달아 보는 경험 + 트래픽이 붙었을 때를 위한 선로 부설"**로 접근할 것.
