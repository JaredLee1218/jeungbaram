# 16. 통계 사이트의 챔피언별 스킬 증강 실측 (광맥 3)

- 조사일: 2026-09-03 (라이브 패치 26.17 — 각 사이트 표기 기준. Riot 내부 버전 표기로는 16.17)
- 대상: op.gg / arammayhem.com / aramgg.com / mayhemmeta.com 4개 통계 사이트의 ARAM: Mayhem(KIWI) 챔피언별 스킬 증강(Ability Augments) 실측 데이터
- 방법: **전 페이지 curl로 원본 HTML 직접 다운로드 → 내장 JSON(Next.js RSC flight / Astro SSR) Node.js 파싱**. WebFetch 요약 경유는 aramgg의 API 플랫폼 문서 1건뿐(그마저 JS 앱이라 실패, §3-3에 표기). 수치는 전부 원본 페이로드에서 기계 추출.
- 선행 스터디(09 스킬 증강 30종 체계, 10 kiwi.bin 데이터마이닝)는 반복하지 않음. 이 문서는 그 잠정 결론("챔피언 매핑은 클라이언트에 없다")을 **통계 사이트의 실측(관측) 데이터**로 우회한 결과다.
- 표본 날짜: arammayhem·aramgg는 "Data date 2026-08-31 / v26.17"을 명시. mayhemmeta는 패치 26.17 선택 상태(수집 시각 2026-09-03). op.gg는 patch "16.17" 필드 확인.

## 0. TL;DR

1. **4개 사이트 모두 스킬 증강의 강화 대상 스킬(Q/W/E/R)은 표시하지 않는다.** 통계는 전부 "챔피언 × 증강" 단위까지만 잡힌다. op.gg가 내장한 증강 사전조차 대상 스킬 자리가 `<font color='#F0C200'>?</font> 스킬` — 즉 **"?" 플레이스홀더 그대로**다. "야스오 Q Multishot 픽률 X%" 같은 스킬 단위 실측은 어느 사이트에도 존재하지 않는다(§6).
2. 대신 **챔피언×증강 매핑은 4사이트에서 풍부하게 실측된다.** 12챔피언 × 26종(라이브 스킬 증강)의 통합 표 완성(§5). op.gg는 챔피언별 전체 증강 통계 표(196~220행)를 SSR에 내장, mayhemmeta는 챔피언별 전체 행(games/승률/픽률)과 **역방향(증강→전 챔피언) 페이지**를 내장한다.
3. **역방향 페이지가 전 챔피언 확장의 최적 경로**: mayhemmeta `/augments/{id}` 26페이지만 받으면 라이브 스킬 증강 전체의 "100판 이상 챔피언 명단+승률+픽률" 매트릭스가 나온다(이번 조사에서 실제로 1,403개 챔피언×증강 쌍 확보, §4).
4. **챔피언 필터(eligibility)의 실측 증거**: 지형 생성됨=6챔프(트런들/애니비아/자르반4세/오른/아지르/탈리야), 공포=11챔프, 꽁!=13챔프(전원 강화 평타 스킬 보유), 자비의 일격=11챔프(전원 인챈터), 원기 회복=13챔프 vs 빵과 버터=162챔프. kiwi.bin의 요구 속성 태그(스터디 10 §1.3)가 실제 드로우에 반영됨을 통계로 확인(§4).
5. **징크스 특이 사례**: 12챔프 중 유일하게 스킬 증강이 사실상 2종(빵과 잼/빵과 치즈)만 관측. Q가 쿨다운 없는 토글이라 **빵과 버터(Q 가속)조차 제시되지 않는다** — 스킬 슬롯 단위 적격성 판정의 간접 증거(§5).
6. **스터디 09 §7-1의 티어 상충 3건 해소**: 라이브 26.17 기준 꽁!(BONK!)=**골드**, 공포(Terror)=**골드**, 위력 추구(Pursuit of Power)=**골드**. op.gg(rarity 필드)·mayhemmeta(인덱스)·kiwi.bin(스터디 10)이 전부 일치 → 위키 모듈(실버×2, 골드)과 26.12 노트(프리즘/골드/실버)는 현행과 불일치(§7).
7. 부수 확인: 사이트별 데이터 계보 — aramgg·arammayhem은 **텐센트 CN 클라이언트 집계**(동일 픽률, 데이터 날짜 공유), op.gg의 승률·픽률도 CN 수치와 강한 상관(perf≈CN승률×1.7, popular≈픽률÷4 — 추정), mayhemmeta는 별도 표본(출처 미표기, §3-4).

## 1. 결론부터: "스킬 지정까지 표시되는가?" — 아니오 (4/4 사이트)

| 사이트 | 스킬 증강 표시 단위 | 대상 스킬(Q/W/E/R) 표기 | 근거 |
|---|---|---|---|
| op.gg | 증강 단위 (챔피언별 통계 표) | **없음** — 설명·툴팁의 스킬 자리가 전부 `?` | 야스오 증강 탭 내장 사전: 흡수 desc = "적 챔피언에게 `?` 스킬로 피해를 입히면 체력을 회복합니다." (flight 데이터 원문) |
| arammayhem.com | 증강 단위 (Best Augments 18종/챔프) | **없음** | 야스오 빌드 페이지: "Silver Siphon Appearance rate: 9.05% Win rate: 51.43%" — 스킬 표기 無 |
| aramgg.com | 증강 단위 (챔피언별 톱20 표) | **없음** | 증강 페이지 설명도 "Damaging enemy champions with ? heals you." — `?` 그대로 |
| mayhemmeta.com | 증강 단위 (챔피언별 전체 표) | **없음** | 챔피언 페이지 행 스키마: {id, name, rarity, games, win_rate, pick_rate, baseline_win_rate} — 스킬 필드 없음 |

- 유일한 예외적 흔적: arammayhem의 커뮤니티 콤보 텍스트에 스킬이 자유 서술로 등장한다(예: 야스오 Mystic Punch 콤보 — "Yasuo's Q counts as an auto, so at 1.33s Q CD, you get infinite Q"). 구조화 데이터는 아니다.

## 2. 사이트별 데이터 획득 방법 (URL 패턴·내장 JSON·확장성)

### 2-1. op.gg — 챔피언별 "증강 탭" SSR 내장 JSON (완전 카탈로그)

- URL 패턴: `https://op.gg/ko/lol/modes/aram-mayhem/{챔피언슬러그}/augments` (탭: `/build`, `/items`, `/skills`도 존재. 챔피언 목록은 `https://op.gg/ko/lol/modes/aram-mayhem`)
- 획득법: HTML 내 `self.__next_f.push([1,"..."])` 청크(RSC flight)를 이어붙여 JSON 문자열 복원 → `"data":[{...}]` 배열 추출.
- **핵심 스키마** (챔피언당 196~220행 = 그 챔피언에게 통계가 잡힌 전체 증강):
  ```json
  {"id":2073, "tier":0, "performance":89.25, "popular":2.78,
   "name":"흡수", "key":"ARAM_SustainingStrike", "rarity":1,
   "largeIcon":".../GenericAbilityAugmentIcon_Silver.png", "desc":"...? 스킬로...", "tooltip":"..."}
  ```
  - `id` = **Riot AugmentPlatformId와 일치**(kiwi.bin, 스터디 10 §1.2와 동일 체계 — 예: 2055=다중 공격, 2078=연쇄 반응). `key` = **kiwi.bin AugmentNameId와 문자열 일치**(ARAM_SustainingStrike, SpellVolley 등). 사이트↔게임데이터 조인이 ID로 가능.
  - `rarity`: 1=실버, 4=골드, 8=프리즘. `tier`: 0~5 (op.gg 자체 등급, 낮을수록 좋음; popular 0% 행은 일괄 t5).
  - `performance`/`popular`: §3-2에서 해석. patch 필드 "16.17".
  - 스킬 증강은 아이콘이 `GenericAbilityAugmentIcon_{Silver|Gold|Prismatic}.png`(전용 아이콘 9종 제외) — 게임 내 범용 아이콘 체계(스터디 10 §1.6) 그대로.
- 12챔피언 파싱 결과: 챔피언×스킬증강 쌍 154건 관측(popular=0%인 잔존 표본 포함). 12챔프 카탈로그 합집합 = 증강 261종(비활성 공허 돌진 등 레거시 포함).
- 빌드 탭(`/build`)에는 "좋은/나쁜 증강" 위젯(5+5종)만 SSR로 실림 — 야스오의 경우 흡수가 나쁜 증강 쪽에 표시(빨간 아이콘).
- **확장성: 상**. 슬러그만 바꾸면 전 챔피언(173) 즉시 수집 가능. 페이지당 ~860KB, SSR이라 JS 실행 불필요.

### 2-2. arammayhem.com — Astro 정적 SSR (Best Augments 18종 + 역방향 페이지 + 콤보 666)

- URL 패턴: 챔피언 `https://arammayhem.com/build/{슬러그}/`, 증강 `https://arammayhem.com/augments/{증강슬러그}/`(예: /augments/multishot/)
- 챔피언 페이지: "Best Augments for {챔프}" 섹션에 티어별(프리즘/골드/실버) 각 6종 = **18종만** 노출. 각 항목 "Appearance rate: X% / Win rate: Y%".
  - ⚠️ **함정: Win rate는 챔피언별 수치가 아니라 그 증강의 전역 승률이다.** 증거: ① 확고한 의지로가 말파이트/다리우스/헤카림 페이지에서 모두 52.76%로 동일. ② 럭스 페이지의 다중 공격 46.47% = Multishot 증강 페이지의 전역 승률 46.47%(2026-09-01 스냅샷). ③ 야스오 페이지의 흡수 51.43% = aramgg 흡수 증강 페이지의 전역 승률 51.43%. **Appearance rate만 챔피언별**이며, 이는 aramgg의 챔피언별 픽률과 완전 일치(동일 원천).
  - 페이지 상단에 챔피언 요약(승률/픽률/티어/순위, "Data date 2026-08-31", "Patch: 26.17").
  - 일부 챔피언은 증강 섹션 자체가 없다(**애쉬 페이지에는 Best Augments 섹션 없음** — 티어 C, 사유 미표기).
- 증강 페이지: "Specifically Recommended"(챔피언별 티어·순위·픽률 8종 내외) + Top Champions + **패치별 스냅샷 추이 표**(날짜·패치·전역 순위·승률·픽률 — 예: Multishot 2026-09-01 #164 46.47%/6.34% ← 스터디 09 §8 수치와 일치) + 커뮤니티 콤보.
- 콤보 666종은 커뮤니티 제출 + 큐레이션(챔피언 페이지에 "Community Submitted Combos", 증강 조합 단위, 자유 텍스트 설명).
- **확장성: 중**. 정적 HTML이라 파싱 쉽지만 챔피언당 18종 제한 + 승률이 전역값이라 챔피언별 승률 소스로는 부적합. 증강별 추천 챔피언·추이용으로 유용.

### 2-3. aramgg.com — CN(텐센트) 클라이언트 집계, 챔피언 숫자 ID

- URL 패턴: 챔피언 `https://aramgg.com/en/champion-stats/{챔피언숫자ID}`(예: 야스오 157, 소라카 16 — Riot championId), 증강 `https://aramgg.com/en/augments/{AugmentPlatformId}`
- 데이터 출처(사이트 원문): *"Win rates use aggregated, anonymously uploaded CN client matches. Champion Augments require 255 games and three-Augment combos require 151 games to appear."* / "Tencent China public statistics, updated Aug 31, 2026" / "v26.17 · 2026-08-31"
- 챔피언 페이지: 증강 표(순위/이름/자체 티어 T1~/승률/픽률). **SSR에는 톱20만** 실리고 "Show All 125" 등 전체(챔피언당 106~136종)는 JS 로드. 표본 미달 증강은 승률이 "—"로 표시. 그 외 3증강 콤보 TOP5(판수 포함), 스킬 마스터 순서(픽률/승률/판수), 소환사 주문.
- 증강 페이지: 전역 승률·픽률 + "Best Champions" 5명(명단만) — 챔피언별 수치 없음.
- 유료 데이터 API 플랫폼 링크: `https://data.dtodo.cn/developer.html`("aramgg.com Data API"; 아이콘 CDN도 cdn.dtodo.cn). 상세 스펙은 JS 앱이라 미확인 ❓.
- **확장성: 중상**. 챔피언 ID 매핑만 있으면 전 챔피언 순회 가능(172챔프 커버 명시). 단 SSR 톱20 제한 — 스킬 증강은 픽률이 낮아 톱20에 드는 경우가 드물다(12챔프에서 총 15건만 톱20 진입).

### 2-4. mayhemmeta.com — Next.js flight에 전체 행 내장 + 역방향 페이지 (이번 조사 최고 수확)

- URL 패턴: 챔피언 `https://mayhemmeta.com/champions/{슬러그}?patch=16.17`, 증강 `https://mayhemmeta.com/augments/{AugmentPlatformId}?patch=16.17`, 인덱스 `/augments`, 패치 셀렉터 26.15/26.16/26.17.
- 챔피언 페이지: flight 데이터에 **그 챔피언의 전체 증강 행(107~136종)이 통째로 내장** — 스키마: `{"id":2073,"name":"Siphon","rarity":"Silver","games":1651,"win_rate":"54.45","pick_rate":"12.35","baseline_win_rate":"53.35"}` (baseline = 그 챔피언의 평균 승률 → 표시상 "Win Rate Diff"). 챔피언 총 판수도 표시(예: 야스오 13,364게임/26.17). UI는 15행 페이지네이션이지만 데이터는 전량 SSR.
- **증강 페이지(역방향)**: 헤더(전역 승률 순위 #N/209, 승률, De-mirrored WR, 픽률, 총 판수) + **"All Champions N champions · win rate at 100+ games"** — 그 증강이 100판 이상 잡힌 전 챔피언 행이 flight에 전량 내장(`{"id":89,"name":"Leona",...,"games":2474,"win_rate":"49.92","pick_rate":"14.63","baseline_win_rate":"50.06","href":"/champions/leona..."}`). 여기에 클래스 필터, 코픽 증강 통계까지.
- 데이터 출처: 사이트에 미표기(면책 조항뿐) ❓. 표본·수치가 aramgg(CN)와 다르므로 별도 계보(픽률 예: 야스오 흡수 mm 12.35% vs CN 9.05%).
- 증강 인덱스에서 id↔이름↔등급 210종 추출 완료(`mm-augment-index.json`).
- **확장성: 최상**. 두 방향 모두 전량 내장: ① 챔피언 173페이지 → 챔피언별 전체 증강, ② **증강 26페이지 → 라이브 스킬 증강 전체의 챔피언 매트릭스(이번에 실제 수행)**.

## 3. 사이트 간 데이터 계보와 교차 검증

### 3-1. arammayhem = aramgg 원천 공유 (확정적)

- 12챔프 전수에서 arammayhem "Appearance rate" == aramgg "Pick Rate" (야스오 흡수 9.05=9.05, 헤카림 빵과 버터 10.94=10.94, 럭스 다중 공격 4.76=4.76 등 전 항목 일치). 데이터 날짜도 동일(2026-08-31).
- 차이: arammayhem은 챔피언별 승률을 싣지 않고 전역 승률을 병기(§2-2 함정), aramgg는 챔피언별 승률(CN) 표시.

### 3-2. op.gg ↔ aramgg(CN) 상관 — op.gg 필드 해석 (추정)

op.gg의 `performance`·`popular`는 라벨이 없는 내부 수치다. aramgg(CN)의 챔피언별 승률·픽률과 대조한 결과:

### 3-3. mayhemmeta는 별도 표본

- 같은 챔피언×증강에서 mm과 CN 수치가 계통적으로 다르다(야스오 흡수: mm 12.35%/54.45% vs CN 9.05%/56.37%). mm은 KDA·멀티킬·소환사 주문 등 매치 상세를 갖고 있어 매치 단위 수집(리전 미상)으로 보인다 ❓.
- 세 계보(CN=aramgg/arammayhem, op.gg, mm)에서 **순위 구조는 대체로 일치**(예: 헤카림의 스킬 증강 톱5가 세 곳 모두 확고한 의지로/빵과 버터/날쌘걸음/적응형 와드/믿음직한 무기).

## 6. 스킬 지정 정보의 대안: "유일성 유추"의 가능 범위 (추론 — 실측 아님)

스킬 단위 실측은 없지만, **요구 속성이 좁은 증강 × 해당 속성 스킬이 1개뿐인 챔피언**의 조합은 대상 스킬이 논리적으로 확정된다. mm 매트릭스와 결합하면:

- **확정적(적격 스킬 유일)**:
  - 지형 생성됨: 트런들 E, 애니비아 W, 자르반 4세 R, 오른 Q, 아지르 R, 탈리야 R (6건 — 각자 지형 스킬이 하나뿐)
  - 꽁!: 오공 Q, 나서스 Q, 잭스 W, 일라오이 W, 베인 Q, 브라이어 W, 쉬바나 Q, 트런들 Q, 다리우스 W, 가렌 Q, 문도 E, 레넥톤 W, 블리츠크랭크 E (13건 — 강화 평타 스킬 유일)
  - 굶주린 속박: 럭스 Q, 소라카 E, 브랜드 Q(점화 대상 기절 = Immobilize) (관측 3챔프 중 3건 유일)
  - 연쇄 반응(헤카림): E(넉백 유일) / 보강(럭스): W(보호막 유일) / 작은 도움·출발할 시간·바늘꽂이(애쉬): Q(지속형 강화 평타 유일)
- **불확정(적격 스킬 복수)**: 주문 분산·다중 공격·3연발(투사체 다수 보유 챔프 — 애쉬 W/R, 브랜드 다수), 속성 무관 증강(흡수·위력 추구·가속 추구·메아리 시전·과충전 등)은 유추 불가. 시스템의 스킬 선택 규칙 자체가 미공개(스터디 09 §9)라 실제 게임에서 어느 스킬이 지정되는지는 여전히 관측 불가 영역.
