## 2. 7가지 질문에 대한 답

### ① 롤 기초 (칼바람/모드 구조) → [raw/01-mode-mechanics.md](raw/01-mode-mechanics.md), [raw/05-champions-items.md](raw/05-champions-items.md)

- 칼바람 나락(ARAM)은 1레인 5v5, 무작위 챔피언, 3레벨 시작, 귀환 불가. 2026 현재는 **맵 3종 로테이션**(칼바람 나락/도살자의 다리/코샨의 교차로 Koeshin's Crossing), 시작 골드 1400, 상점 근접 시에만 구매 가능.
- 아수라장이 일반 칼바람과 다른 점: **룬 완전 비활성**(레벨 비례 체력 등 보상 스탯 지급), 탈진 금지, **콤보 브레이커**(CC를 맞을 때마다 강인함 중첩·3.25초 지속, 최근 7초 중 5초 이상 행동 불가 시 해제+3초 면역), 전용 아이템(**능력치 모루 750G**, ID 220008 실측 일치), 26.03부터 소환사 주문 완전 자유(점멸 강제 폐지), 26.05부터 넥서스 체력 3000. 비교표는 [01 §4](raw/01-mode-mechanics.md).

### ② 챔피언 → [raw/05-champions-items.md](raw/05-champions-items.md)

- 총 **173명**(Data Dragon 16.17.1 실측). 최신 챔피언은 **로크(Locke, 2026-06-24, 2026년 유일 신챔)**, 직전은 자헨(2025-11)·유나라(2025-07)·멜(2025-01).
- `champion.json`(id/key/tags/partype/stats 20종) + 개별 `champion/{Id}.json`(스킬·패시브)로 구조 파악 완료. **ko_KR 완전 지원**(28개 로케일 실측).
- 주의: ddragon 스킬 툴팁은 `{{ qdamage }}` 플레이스홀더 미치환 — 정밀 수치가 필요하면 cdragon `.bin.json` 또는 위키 필요.
- ARAM 챔피언 밸런스(%)는 라이엇 공식 피드가 **없음**(실측 확인). 최선의 기계 판독 소스는 위키 `Module:ChampionData/data`(Lua, 161명분 dmg_dealt/dmg_taken 등 8종 키).

### ③ 증바람 모드 규칙 — 증강 선택+리롤의 정확한 메커니즘 → [raw/01-mode-mechanics.md](raw/01-mode-mechanics.md)

시뮬레이터의 핵심 재현 대상. 전부 독립 재검증된 규칙:

1. **선택 시점**: 레벨 **3(게임 시작)/7/11/15 총 4회**, 매번 **3택1**. (특수 증강으로 5번째 슬롯 가능) — 라이엇 dev 블로그 원문으로 재확인: https://www.leagueoflegends.com/en-us/news/dev/dev-bringing-mayhem-to-aram/
2. **선택 조건**: 레벨을 채워도 **사망 중이거나 우물(상점 활성) 안에 있을 때만** 선택 화면이 열림. 게임을 멈추지 않음.
3. **리롤**: **각 선택 화면에서 3개 슬롯 각각 최대 1회씩** 리롤 가능 → **한 화면 최대 6개 열람**. 리롤 결과는 **같은 등급**의 다른 증강(6개가 동시에 보이는 게 아니라 카드가 교체되는 방식). 팀 공유 재화가 아닌 개인·슬롯 단위 — https://wiki.leagueoflegends.com/en-us/ARAM:_Mayhem
4. **등급**: 실버 < 골드 < 프리즘 3단계. **화면별 등급은 무작위이되 10명 전원 동일**, 유일한 제약은 "**1·2번째 화면이 둘 다 실버일 수 없음**". 등급별 확률 수치는 비공개.
5. **중복 금지**: 한 번 선택지로 등장한 증강은 그 게임에서 재등장하지 않음(아레나와 반대).
6. **황금 리롤**(26.03~): 진행도 트랙 보상. 실버/골드 화면에서 일정 확률로 획득, 사용 시 **한 단계 높은 등급**의 증강으로 교체.

### ④ 최신 증강 목록 현황 → [raw/02-augment-catalog.md](raw/02-augment-catalog.md)

- 위키 데이터 모듈 기준 현행 풀 **225개 전수 수록**: 실버 64 / 골드 85 / 프리즘 76. 이 중 **11개 비활성화**, 3개는 내부 데이터에만 존재. 게임 파일(kiwi.bin.json)은 222개 — 3개 차이는 비활성분 추정.
- **한국어 증강명 225개 전부 확보**(op.gg 내장 데이터 + CommunityDragon 한/영 스트링테이블 키 대조). 원본 [02 §2](raw/02-augment-catalog.md)에 영/한 이름·등급·효과·Arena 유래 여부 전체 표.
- 유래 구분: **128개 Arena 동명(유래 추정) / 97개 Mayhem 전용**.
- 변동 이력: 26.03에서 46종 추가·3종 삭제·핫픽스 3회 → **26.12에서 세트 폐지와 함께 41종 일괄 삭제**(26.03 신규분 13종 포함) + 스킬/퀘스트 증강 59종 추가 → 26.17에서 Ultra Hydra, Upgrade: Death's Dance 추가. **증강 풀은 패치마다 살아 움직이는 데이터**임 — 데이터 갱신 파이프라인이 필수.
- 개발자 언급 전체 풀 "300+"와 위키 225의 차이는 챔피언별 스킬 증강 변형 집계 방식으로 추정(미확인).

### ⑤ 챔피언별 증강 등장 규칙 → [raw/03-champion-augment-pools.md](raw/03-champion-augment-pools.md)

- **증강 풀은 전 챔피언 공통이 아님.** 라이엇 공식 확인: "드로우 풀은 플레이어가 보기 전에 챔피언별로 필터링된다" — https://www.ibtimes.com/league-legends-aram-mayhem-cuts-over-450-ability-augments-live-hotfix-3804331
- **명문화된 제한(위키 Lua 원문)**: Draw Your Sword=원거리 전용+루난 보유 시 제외 / Vampirism=워모그 보유 시 제외(⚠️ Perseverance 상호배제는 미검증) / Earthwake 팀당 2명·Droppybara 팀당 1명 / Overextender=도살자의 다리 맵 전용 / Dashing=칼리스타는 효과가 공속 125%로 치환.
- **스킬 증강(26.12~)은 스킬 속성 필터**: 넉백(Chain Reaction)·투사체(Spell Split)·대상지정+투사체(Tripleshot)·회전(Spin To Win, 위키에 적격 스킬 목록 명시) 보유 챔피언에게만 제시. 부적합 조합 450+가 "dead draws" 문제로 2026-06-19 핫픽스 제거, 26.13에서 적격성 재개선.
- **가중치 체계(개발자 인터뷰, 2026-08-24)**: 챔피언별 1D 배열로 관리, **Optimal(드묾)/Viable/Average(자주)/Invalid(완전 제외)** 4단계 — 실제 매핑 데이터는 비공개. 진행도 트랙 레벨 9 = 자기 스킬 강화 증강 확률 증가.
- 아수라장에 챔피언 **전용** 증강은 없음(아레나에는 쉬바나 등 5종 존재). 아레나의 스탯/메커니즘별 제외 목록(AD 72명, AP 49명, 마나 26명 등)이 같은 계열 시스템의 참고 자료 — 단 V13.17 이후 미갱신.

## 3. 시뮬레이터 설계에 주는 시사점

### 3-1. 랜덤 로직 재현 → 근거: [raw/01](raw/01-mode-mechanics.md), [raw/03](raw/03-champion-augment-pools.md), [raw/08](raw/08-prior-art.md)

- **드래프트 상태 기계**: 4라운드(레벨 3/7/11/15) × [등급 결정 → 3장 드로우 → 슬롯별 1회 리롤(같은 등급) → 1장 확정]. 우리 컨셉 "3+3 리롤"이 실제 규칙과 정확히 일치함이 확인됨([08 §0](raw/08-prior-art.md)).
- **등급 배정**: 화면별 무작위 + "1·2라운드 실버 중복 금지" 제약 반영. 확률 수치는 비공개이므로 **설정 가능한 파라미터**로 두고 합리적 기본값 사용(커뮤니티 실측으로 추후 보정). 황금 리롤은 옵션 토글로.
- **중복 금지**: 게임 내 이미 제시된 증강(리롤로 노출된 것 포함)은 재드로우 제외.
- **챔피언 필터**: 정확한 Optimal/Viable/Average/Invalid 매핑은 비공개이므로 3층 근사 — (1) 위키 명문화 제한(원거리 전용·맵 한정·팀 제한 등) 하드 필터, (2) 스킬 증강은 스킬 속성 태그(투사체/넉백/대상지정/회전) 기반 필터, (3) 마나 증강 등은 아레나 제외 목록을 참고한 휴리스틱(⚠️ 공식 미확인 표기). "실제 게임과 100% 동일"이라 주장하지 말고 "게임 규칙 기반 재현"으로 포지셔닝.

### 3-2. 데이터 소스 → 근거: [raw/04](raw/04-data-api.md), [raw/05](raw/05-champions-items.md), [raw/02](raw/02-augment-catalog.md)

- **증강 DB(한국어)**: cherry-augments.json(ko_kr) ∩ augment-lists.json(KIWI) → kiwi.bin.json 설명 키 → ko_kr 스트링테이블 조회. 아이콘은 cdragon PNG 규칙. 전 단계 URL 실측 검증됨([04 §7](raw/04-data-api.md)).
- **보조**: 위키 Lua 모듈(영문 설명·등급·비활성 표기·등장 조건 노트, CC BY-SA 3.0 — 출처 표시 필요). 등급 불일치 1건(Terror) 등은 [02 §7](raw/02-augment-catalog.md) 참조.
- **챔피언/아이템**: Data Dragon 16.17.1 ko_KR. 빌드 시점에 버전 고정(`/16.17/`) + versions.json 폴링으로 갱신 감지.
- **경기 통계는 설계에서 배제**: API 403이 구조적 제약. 통계는 외부 사이트 링크/수기 큐레이션으로 대체.

### 3-3. 추천 로직 → 근거: [raw/06](raw/06-fun-synergies-kr.md), [raw/07](raw/07-fun-synergies-en.md), [raw/08](raw/08-prior-art.md)

- **차별화 핵심은 "조합 해석"**: 기존 도구는 전부 증강 1개 단위 티어 또는 챔피언+증강 1쌍 콤보까지. **뽑힌 4증강 세트 전체 + 챔피언**을 입력으로 플레이스타일 서사와 아이템을 출력하는 것은 유일 포지션([08 §5](raw/08-prior-art.md)).
- 구현안: 증강에 **시너지 태그**(온힛전이/무한루프/스택/평타증폭/탱킹/도박/전환 등 §2-⑦의 축)를 부여 → 챔피언 태그(tags/partype/스킬 속성)와 매칭 → 태그 조합별 플레이스타일 템플릿 + 아이템 추천(몰왕·리안드리·심장강철 등 축별 코어템) + 커뮤니티 밈 문구("나오면 오픈"급 조합엔 특별 연출).
- 수기 큐레이션 시드: 한국 28종 + 영어권 36종 + arammayhem.com 콤보 666개(참고용) + 나무위키 챔피언별 추천 조합. 함정 증강 경고(날쌘걸음 등)도 넣으면 신뢰도 상승.

## 4. 리스크와 미해결 질문

**구조적 리스크**
1. **패치 변동성**: 증강 풀이 대격변급으로 갈리는 모드(26.12에서 41종 일괄 삭제 전례). → 데이터 파이프라인 자동화 + 버전 고정 필수.
2. **모드 종료 리스크**: "무기한·종료일 없음"까지만 공식 확인, '상시 모드' 선언은 없음. 다만 2027년 콘텐츠 계획 언급으로 낮은 리스크.
3. **정책 리스크**: Riot이 TFT에서 증강 통계를 두 번 차단한 전례([08 §4](raw/08-prior-art.md)). 재미형 시뮬레이터는 통계 차단에도 살아남는 구조지만, '정답 통계' 의존 기능은 피할 것.
4. **경쟁 추격**: arammayhem.com이 이미 미니게임 섹션을 운영 중 — 룰렛류를 따라 만들 수 있음. 선점 속도가 중요.

**⚠️ 미검증/미해결 (원본의 미확인 표기 종합)**
- **등급(실버/골드/프리즘) 등장 확률 수치** — 공식·데이터마이닝 모두 부재. 시뮬레이터 파라미터로 처리 ([01 §6](raw/01-mode-mechanics.md), [03 §7](raw/03-champion-augment-pools.md))
- **챔피언×증강 Optimal/Viable/Average/Invalid 실제 매핑** — 존재만 확인, 데이터 비공개 ([03 §7](raw/03-champion-augment-pools.md))
- 마나 증강이 무마나 챔피언에게 제외되는지 — 아수라장은 정황(팬사이트+실측)만, 공식 미확인
- 리롤 "팀 공유 아님"의 명시적 공식 문구 부재(모든 소스가 개인·슬롯당 1회로 기술)
- 위키 225 vs 게임 파일 222 vs 개발자 언급 300+의 개수 차이 정확한 사유 ([02 §7](raw/02-augment-catalog.md), [04 §8](raw/04-data-api.md))
- 26.03 신규 증강 45 vs 46종 차이, Laser Eyes 현재 상태, Terror 등급 불일치, 현행 진행도 트랙 구성 ([02 §7](raw/02-augment-catalog.md))
- Mayhem 경기 공개 시 playerAugment1~6 채움 여부, 라이브 큐 ID(2400/2401/2403/2405), LCU 로컬 전적 접근 실증 ([04 §8](raw/04-data-api.md))
- 일부 증강('광대 대학', '프로틴 음료', '대변혁' 등)의 게임 내 정확한 효과 원문 — 커뮤니티 서술만 확보 ([06 §7](raw/06-fun-synergies-kr.md))
- Vampirism↔Perseverance 상호배제(위키 단일 소스), 콤보 브레이커 중첩당 강인함 %수치

2. **드래프트 엔진 구현**: §3-1의 상태 기계(4라운드 × 3택1 × 슬롯별 리롤 × 등급 제약 × 중복 금지)를 순수 함수로 구현 — 규칙은 전부 확정 문서화되어 있어 즉시 착수 가능.
3. **챔피언 필터 v1**: 위키 명문화 제한 + 스킬 속성 태그(kiwi.bin.json/championFull 기반)로 하드 필터만 우선 적용. 가중치는 v2로 미룸.
4. **시너지 태그 스키마 + 시드 큐레이션**: [06](raw/06-fun-synergies-kr.md)·[07](raw/07-fun-synergies-en.md)의 조합 64종+를 태그화해 추천 로직 시드로 입력. 밈/용어 사전을 UI 카피에 반영.
5. **MVP 범위 확정**: 챔피언 랜덤/선택 → 4라운드 드래프트 체험 → 조합 해석 카드(플레이스타일+아이템+밈 한 줄) → 공유 기능. 통계·오버레이는 범위 밖(기존 사이트 링크로 대체).
6. **후속 조사(선택)**: 실게임 표본으로 등급 확률 실측, 나무위키 챔피언별 추천 조합 후반부·아카라이브 본문 확보, LCU 본인 전적 접근 실증.
